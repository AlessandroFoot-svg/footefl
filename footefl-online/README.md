# FootEFL

Football Linguistique — si gioca una partita e si impara l'inglese.

- **index.html** — l'app dell'alunno. È quella che si apre all'indirizzo del sito.
- **prof.html** — la piattaforma del professore: classi, squadre, dettati, correzioni.
- **d/** — i dati pubblicati: `index.json` e un file per competizione.
  Li genera la piattaforma del professore, dal pulsante **PUBBLICA**.

Tutto gira nel browser. Non c'è nessun server, nessun database, nessun account:
quello che un telefono salva resta su quel telefono.

Nella cartella `d/` non va mai il nome di un alunno: ci vanno i codici.
